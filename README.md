# Collaborative-Project-Management-Web-Application

A full-stack team collaboration platform designed to help teams manage projects, tasks, and communication in a centralized workspace.

## Technologies Used

- React.js
- Spring Boot
- Spring JPA
- MySQL
- RESTful APIs
- Spring Starter Mail
- Razorpay API

## Project Overview

- Designed and developed a backend system that enables teams to collaborate efficiently on projects.
- Team leads can create projects, add team members, assign tasks, and manage project activities.
- Team members can collaborate through dedicated chat functionality and task comments.

## Implementation

- Developed the frontend using React.js for an interactive user experience.
- Built the backend using Spring Boot and Spring JPA with MySQL for data management.
- Implemented RESTful APIs for seamless communication between frontend and backend services.
- Integrated Spring Starter Mail for sending project invitations and team notifications.
- Integrated Razorpay API for managing subscription-based access to premium features.
